# Wang Min Homepage (Bilingual)


## Structure

- `index.html`: page layout and profile content
- `assets/css/style.css`: visual style (masthead + sidebar + content)
- `assets/js/i18n.js`: Chinese/English switch logic and text dictionary
- `assets/img/wangmin.jpg`: profile photo

## How to edit

- Update text keys in `assets/js/i18n.js` for both `zh` and `en`
- Update publications directly in `index.html` under `#publications`
- Update links in sidebar/contact section in `index.html`

## Deploy to GitHub Pages

1. Push all files to your GitHub repository.
2. Open repository `Settings -> Pages`.
3. Source: your default branch, folder `/ (root)`.
4. Visit your Pages URL after build finishes.
